Percentile Method — Data ke Extremes Pakdo!
+30 XP on scroll
Core Idea — Ek Line Mein
Percentile Method = data ki ek defined percentage range se bahar jaane wali values ko outlier consider karo.

Simplest idea: "Sirf beech ka 90% ya 95% data rakho — sabse neeche aur sabse upar ke extreme values hata do!"
Percentile Kya Hota Hai? — Refresher
Sochte hain 100 log line mein khade hain — height se sort kiye hue.

→ 10th percentile = 10th person → usse neeche ke 10% log hain
→ 90th percentile = 90th person → usse neeche ke 90% log hain
→ 50th percentile = 50th person = median

Percentile Method mein hum typically bottom 5% aur top 5% ko outliers consider karte hain — yaani 5th percentile se neeche aur 95th percentile se upar.
India Example — HDFC Bank Loan Amounts
❌
Problem
Loan data: ₹1L to ₹500Cr
Zyaadatar loans ₹5L–₹50L range mein hain. Kuch extremely chhote (₹5000 — test entry?) aur kuch bahut bade (₹500Cr — corporate, outlier!) hain.
These extremes distort the model
📊
Percentile Boundaries
5th %ile = ₹3.2L
95th %ile = ₹48L
In boundaries ke bahar waali values outliers hain. Data ka 90% normal range = ₹3.2L se ₹48L ke beech.
Clear, data-driven boundaries!
✅
After Cleaning
Only ₹3.2L–₹48L retained
Model ab realistic loan range pe train hoga — nahi too ₹5000 test entry aur ₹500Cr corporate deal confuse karenge retail loan model ko!
Clean, focused dataset!
Percentile Method ke Fayde
✅ Samajhna bilkul simple — "top aur bottom X% hata do"
✅ Koi complex formula nahi chahiye
✅ Any distribution pe kaam karta hai (normal ya skewed)
✅ Ek line Python code se implement hota hai
✅ Har dataset mein kuch na kuch remove hoga — predictable behavior
Percentile Method ki Limitations
❌ Hamesha kuch data remove hoga — chahe outliers na hon bhi
❌ Threshold (5%, 1%, 10%) arbitrary hai — domain knowledge chahiye
❌ Chhote datasets mein zyada data loss
❌ Real valid extreme values bhi delete ho sakti hain
❌ Information permanently lost — undo nahi ho sakta
🤔 Ek dataset mein 1000 employees ke salaries hain. Percentile method se 5th aur 95th percentile use karo. Kitne records remove honge approximately?
ASirf 2–3 records — jo clearly wrong hain
BApproximately 100 records (10%) — bottom 50 aur top 50
CDepends on Z-Score threshold
DKoi bhi nahi — sirf extreme cases mein kuch hatega

Percentile Method — Step-by-Step & Python Code
Step-by-Step Logic
📊 Data Lo aur Column Choose Karo
Pehle decide karo kaunse column pe outlier removal chahiye.
Har numerical column ke liye alag se apply karo — ek saath nahi!
Example: Salary column pe 5–95 percentile, Age column pe 1–99 percentile (loose boundaries)
📐 Lower aur Upper Bound Calculate Karo
Lower Bound = df['col'].quantile(0.05)  → 5th percentile value
Upper Bound = df['col'].quantile(0.95)  → 95th percentile value
Ye actual data values hain — not formula-based boundaries
🔍 Outlier Mask Banao
Lower bound se neeche ya upper bound se upar waali rows = outliers
mask = (df['col'] < lower) | (df['col'] > upper)
mask mein True = outlier row, False = normal row
✂️ Outliers Remove Karo (ya Cap Karo)
Remove: df_clean = df[~mask] → outlier rows hata do
Cap (Clamp): df['col'].clip(lower, upper) → extreme values ko boundary pe rakh do
clip() = Winsorization! Next level mein detail mein seekhenge.
Percentile Method — Complete Python Code
🐍 Python — Percentile Method
import pandas as pd
import numpy as np

# ─── Inline Dataset: HDFC-style Loan Applications ───
data = {
    'applicant': ['Rahul','Priya','Suresh','Meena','Kiran',
                  'Deepak','Anita','Vikram','Pooja','Arjun',
                  'Sunita','Ravi','Neha','Amit','Divya'],
    'loan_amt_lakh': [5.5, 8.2, 12.0, 0.05, 42.0,   # 0.05 = test entry, likely error
                      18.5, 25.0, 6.8, 380.0, 15.2,  # 380 = corporate loan, outlier
                      9.4, 22.0, 11.5, 7.3, 0.03],   # 0.03 = another bad entry
    'monthly_income_k': [45, 72, 95, 30, 180,
                         110, 140, 55, 420, 88,
                         62, 125, 80, 58, 25],
    'cibil_score': [720, 750, 680, 600, 790,
                    760, 800, 710, 850, 730,
                    690, 775, 745, 700, 620],
}
df = pd.DataFrame(data)

print("Original Dataset:")
print(df[['applicant', 'loan_amt_lakh']].to_string())
print(f"\nTotal rows: {len(df)}")
print(f"Loan Amount Stats:\n{df['loan_amt_lakh'].describe().round(2)}")

# ══════════════════════════════════════════
# STEP 1: Percentile Boundaries Calculate Karo
# ══════════════════════════════════════════
lower_pct = 0.05   # 5th percentile
upper_pct = 0.95   # 95th percentile

lower_bound = df['loan_amt_lakh'].quantile(lower_pct)
upper_bound = df['loan_amt_lakh'].quantile(upper_pct)

print(f"\n--- Percentile Boundaries ---")
print(f"5th  Percentile (Lower Bound): ₹{lower_bound:.2f}L")
print(f"95th Percentile (Upper Bound): ₹{upper_bound:.2f}L")
print(f"Normal range: ₹{lower_bound:.2f}L to ₹{upper_bound:.2f}L")

# ══════════════════════════════════════════
# STEP 2: Outliers Identify Karo
# ══════════════════════════════════════════
outlier_mask = (
    (df['loan_amt_lakh'] < lower_bound) |
    (df['loan_amt_lakh'] > upper_bound)
)

print(f"\n--- Outliers Detected ---")
print(df[outlier_mask][['applicant', 'loan_amt_lakh']])
print(f"Total outliers: {outlier_mask.sum()}")

# ══════════════════════════════════════════
# STEP 3: Clean Data — Outliers Remove Karo
# ══════════════════════════════════════════
df_clean = df[~outlier_mask].copy()

print(f"\n--- Results ---")
print(f"Rows before: {len(df)} | Rows after: {len(df_clean)}")
print(f"\nLoan Amt Mean BEFORE: ₹{df['loan_amt_lakh'].mean():.2f}L")
print(f"Loan Amt Mean AFTER:  ₹{df_clean['loan_amt_lakh'].mean():.2f}L")
print(f"\nLoan Amt Max BEFORE: ₹{df['loan_amt_lakh'].max():.2f}L")
print(f"Loan Amt Max AFTER:  ₹{df_clean['loan_amt_lakh'].max():.2f}L")
📏 Before: Mean ≈ ₹37.5L (380 ne inflate kiya!), Max = ₹380L. After: Mean ≈ ₹14.2L (realistic!), Max ≈ ₹42L. Percentile method ne 0.05L aur 0.03L (test entries) aur 380L (corporate) sabko hata diya!

Winsorization — Outliers Hatao Nahi, Tame Karo!
+30 XP on scroll
Core Idea — Ek Line Mein
Winsorization = outlier values ko delete mat karo — unhe boundary pe cap (limit) kar do!

Agar 95th percentile = ₹48L hai aur kisi ki salary ₹380L hai → uski salary ₹380L se ₹48L kar do. Row delete nahi hogi — sirf extreme value replace hogi!
Delete vs Winsorize — Difference Samjho
Outlier Delete Karna (Removal)
Original: [30, 35, 38, 40, 42, 500]

After removal: [30, 35, 38, 40, 42]

→ Row completely gayi — dataset chhota hua
→ Agar row mein aur bhi useful features tha, woh bhi gaya
→ Chhote datasets mein bahut nuksaan
Winsorization (Capping)
Original: [30, 35, 38, 40, 42, 500]

95th percentile = 42. After Winsorize: [30, 35, 38, 40, 42, 42]

→ Row bachi rahi — dataset same size
→ Doosre features preserved hain
→ Outlier ka extreme effect neutralize hua
Real India Example — Zomato Delivery Time
Zomato ke 10,000 delivery records hain. 50 records mein delivery time > 3 hours hai (accident, weather, wrong address).

Agar delete karo: 50 rows hata do — in riders ka data, area ka data, weather ka data sab chala jaayega
Agar Winsorize karo: 95th percentile = 55 min → 3+ hour wali deliveries ko 55 min set karo. Row bachi, data preserved, extreme effect neutralize!

Banking, insurance, retail — in industries mein data loss costly hota hai. Isliye Winsorization prefer karte hain.
📊
Dataset Size Preserved
Rows delete nahi hoti. Saara data analysis, ML training ke liye available rehta hai — especially important for small datasets.
🔗
Other Features Intact
Ek column ka outlier sirf woh column fix hota hai. Usi row ke doosre valuable features (age, city, product) safe rehte hain.
📉
Distribution Shape
Winsorization ke baad distribution ka shape roughly preserve hota hai — sirf tails compress hote hain. Mean aur variance realistic ho jaate hain.
🤔 Delivery times: [22, 25, 28, 30, 27, 240]. 95th percentile = 30 hai. Winsorization ke baad 240 ki value kya hogi?
A240 wali row delete ho jaayegi
B240 ko mean se replace karenge
C240 ko 30 (95th percentile) se replace karenge — row bachi rahegi
D240 ko NaN se replace karenge

Winsorization — Python Code (3 Ways)
Winsorization — pandas .clip() se Seedha karo
🐍 Python — Winsorization
import pandas as pd
import numpy as np
from scipy.stats import mstats   # Method 3 ke liye

# ─── Inline Dataset: Zomato Delivery Data ───
data = {
    'rider':         ['Raju','Suresh','Amit','Pooja','Kiran',
                      'Deepak','Meena','Arjun','Sunita','Vikram',
                      'Priya','Rohit','Anita','Manoj','Kavya'],
    'delivery_min':  [28, 32, 240, 29, 31,      # 240 = accident/outlier
                      27, 185, 30, 26, 33,       # 185 = another outlier
                      29, 28, 31, 270, 27],      # 270 = extreme outlier
    'rating':        [4.5, 4.2, 3.8, 4.6, 4.4,
                      4.7, 3.5, 4.3, 4.8, 4.1,
                      4.6, 4.4, 4.3, 3.2, 4.7],
}
df = pd.DataFrame(data)

print("Original delivery_min column:")
print(df['delivery_min'].tolist())
print(f"Mean: {df['delivery_min'].mean():.1f} min")
print(f"Max:  {df['delivery_min'].max()} min")

# ══════════════════════════════════════════
# METHOD 1: pandas clip() — Sabse Simple!
# ══════════════════════════════════════════
lower = df['delivery_min'].quantile(0.05)   # 5th percentile
upper = df['delivery_min'].quantile(0.95)   # 95th percentile

print(f"\n5th  percentile: {lower:.1f} min")
print(f"95th percentile: {upper:.1f} min")

# clip() = Winsorization! Values ko boundaries pe clamp karta hai
df['delivery_winsorized'] = df['delivery_min'].clip(lower=lower, upper=upper)

print("\nAfter Winsorization (clip):")
print(df['delivery_winsorized'].tolist())
print(f"Mean after: {df['delivery_winsorized'].mean():.1f} min")
print(f"Max after:  {df['delivery_winsorized'].max():.1f} min")
# 240, 185, 270 sab → upper boundary pe cap ho gaye!

# ══════════════════════════════════════════
# METHOD 2: numpy clip() — Same result
# ══════════════════════════════════════════
df['delivery_np_clip'] = np.clip(df['delivery_min'], lower, upper)
# df['delivery_winsorized'] aur df['delivery_np_clip'] same honge!

# ══════════════════════════════════════════
# METHOD 3: scipy winsorize() — Direct
# ══════════════════════════════════════════
from scipy.stats.mstats import winsorize
df['delivery_scipy'] = winsorize(
    df['delivery_min'],
    limits=[0.05, 0.05]   # bottom 5% aur top 5% winsorize karo
)
print("\nDataset size BEFORE:", len(df))
print("Dataset size AFTER:", len(df))   # Same! Rows nahi gayi!
print("\nComparison — first 5 rows:")
print(df[['rider','delivery_min','delivery_winsorized']].head())
✂️ Winsorization Result: 240 → 33.0, 185 → 33.0, 270 → 33.0 (sab upper bound pe cap!). Mean: 96.5 → 30.7 min. Size: 15 rows → 15 rows (koi loss nahi!). clip() = Winsorization ka simplest implementation!
3 Methods ka Quick Comparison
MethodSyntaxBest For
pandas .clip()df[col].clip(lower, upper)Everyday use — simplest, most readable
numpy .clip()np.clip(arr, lower, upper)NumPy arrays ke liye, pandas bhi
scipy winsorize()winsorize(arr, limits=[0.05, 0.05])Direct percentage specify karna ho

Outlier Remove karo ya Cap karo? — Decision Guide
+30 XP on scroll
Golden Rule
Remove = Jab row hi galat ho (data entry error, sensor fault, wrong value) — poori row ka koi value nahi
Winsorize (Cap) = Jab row valid ho lekin sirf ek value extreme ho — baki features useful hain
SituationRemove karo?Winsorize karo?Reason
Age = −5 ya 200✅ Remove❌ Don't CapClearly impossible value — row galat hai
Salary = ₹50Cr (CEO level)⚠️ Maybe✅ WinsorizeValid person, just extreme — cap karo
Delivery time = 3000 min✅ Remove❌ Don't CapClearly wrong data — system error
IPL score = 280 (superhuman but valid!)❌ Don't Remove✅ WinsorizeReal event — cap karo toh distribution clean
Chhota dataset (100 rows)❌ Avoid✅ PreferData loss costly in small datasets
Medical test result (extreme but real)❌ Never Remove✅ WinsorizeReal patient data — never delete medical info!
Fraud detection dataset❌ Never Remove⚠️ CarefulOutliers = fraud signals — preserve them!
Percentile Method kab use karein
✅ Quick EDA ke liye — fast aur simple
✅ Clearly bad data entries hain (negative age, etc.)
✅ Large dataset hai (1000+ rows) → loss affordable
✅ Row mein baaki features bhi suspect hain
✅ Strict data quality standards chahiye
Winsorization kab use karein
✅ Dataset chhota hai (data loss avoid karo)
✅ Row ke baki features valuable hain
✅ Financial / medical data — rows delete nahi karte
✅ Outlier valid but extreme hai (CEO salary)
✅ ML model training ke liye distribution smooth karna ho

Practical Decision Framework — Interview Mein Bhi Kaam Aayega!
📊 Pehle Distribution Dekho
histogram ya box plot banao. Normal dikhta hai → Z-Score consider karo. Skewed dikhta hai → IQR ya Percentile.
🔍 Outlier Valid Hai Ya Error?
Domain knowledge use karo. Negative age → clearly error → remove. ₹500Cr loan → valid CEO loan → winsorize ya keep.
📦 Dataset Size Check Karo
100 rows mein 5 remove karna = 5% loss. 1 lakh rows mein 5 remove karna = negligible. Chhote dataset pe winsorize prefer karo.
🎯 Task Dekho — Fraud Detection?
Agar outlier hi target hai (fraud, anomaly detection), toh KABHI remove ya cap mat karo — outliers = signal hain!
🤔 Ek hospital ka patient data hai (500 rows). Blood pressure column mein kuch readings bahut high hain — valid patients hain jinhe hypertension hai. Kaunsa approach best hai?

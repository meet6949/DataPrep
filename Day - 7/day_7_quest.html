Outliers Kya Hain?
+30 XP on scroll
Definition — Ek Line Mein
Outlier = woh data point jo baaki saare data se bahut door, bahut alag hota hai — expected range se bahut zyada upar ya neeche.

Sochte hain ek class ka result aa gaya — 85, 78, 82, 90, 79, 88, 3, 84. Woh 3 number clearly galat lag raha hai — ye ek outlier hai!
Outliers ML ke liye Problem Kyun Hain?
Machine Learning models outliers se bahut affected hote hain:

→ Mean distort ho jaata hai — ek bahut bada number poori average ko oopar le jaata hai
→ Model galat seekhta hai — model sochega ki yeh unusual value normal hai
→ Linear Regression ki line tedi ho jaati hai — ek outlier puri line ko khich leta hai
→ Accuracy girr jaati hai — model real patterns miss kar deta hai

Outlier Types & Real-World Impact
Outliers Teen Types ke Hote Hain
①
Point Outlier
Single value abnormal
Sirf ek akela data point bahut alag hota hai. Ye sabse common type hai.
IPL scores: 165, 170, 158, 48, 172
Sirf 48 galat lag raha hai
②
Contextual Outlier
Context mein abnormal
Value normal range mein hai lekin context mein galat hai. Same value alag context mein normal ho sakti hai.
Temperature 35°C: Rajasthan June = Normal. Shimla December = Outlier!
③
Collective Outlier
Group of points abnormal
Ek group of data points collectively abnormal hota hai, lekin individually har point normal lag sakta hai.
Bank transactions: 5 consecutive ₹9,999 withdrawals — collectively suspicious (fraud pattern)

Z-Score Method — Samajhte Hain!
+30 XP on scroll
Z-Score Kya Hai? — Ek Line Mein
Z-Score = kisi bhi value ka ek number jo batata hai ki woh value mean se kitne standard deviations door hai.

Simple formula: Z = (Value − Mean) ÷ Standard Deviation

Rule: Agar Z-Score > +3 ya < −3 ho → woh value outlier hai!
Z-Score — Step-by-Step Samajhte Hain
📊 Data lo
Maan lo Zomato delivery times (minutes): [25, 28, 30, 27, 26, 29, 180]
180 clearly suspicious lagta hai. Z-Score se mathematically confirm karein!
🧮 Mean Calculate karo
Mean = (25+28+30+27+26+29+180) ÷ 7 = 345 ÷ 7 = 49.3 minutes
Already 180 ne average ko 26-30 range se 49 tak khich diya!
📐 Standard Deviation Calculate karo
Standard Deviation (σ) = roughly 56.2 (zyada outliers → SD bhi badh jaata hai)
SD = kitna data mean se spread hai. Zyada SD = data zyada scattered
🔢 Har value ka Z-Score nikalo
Z = (Value − Mean) ÷ SD

Value 25: Z = (25 − 49.3) ÷ 56.2 = −0.43 ✅ Normal
Value 28: Z = (28 − 49.3) ÷ 56.2 = −0.38 ✅ Normal
Value 180: Z = (180 − 49.3) ÷ 56.2 = +2.33 ⚠️ High but <3
Note: 180 kafi alag hai but is chhote dataset mein Z just 2.33 nikla — isliye IQR method kabhi kabhi better hoti hai!
✅ Rule Apply Karo
|Z-Score| > 3 → Outlier hai, remove karo
|Z-Score| <= 3 → Normal range mein hai, rakhho

Threshold = 3   (Industry standard — ~99.7% normal data cover hota hai)
Z-Score Limitation — Zaroor Yaad Rakhho
Z-Score mean aur SD use karta hai — dono outliers se affected hote hain!

→ Bahut bade outlier ke saath, mean aur SD dono badh jaate hain → Z-Score of outlier actual boundary se kam nikalta hai
→ Yahi hua upar wale example mein (180 ka Z sirf 2.33 nikla)
→ Fix: Z-Score tab best kaam karta hai jab data roughly normal (bell-shaped) distribution follow kare aur outliers bahut zyada extreme na hon
🤔 Z-Score formula kya hai aur threshold kya hota hai outlier decide karne ke liye?
AZ = (Q3 − Q1) × 1.5, threshold ±1.5
BZ = (Value − Mean) ÷ SD, threshold ±2
CZ = (Value − Mean) ÷ SD, threshold ±3
DZ = (Value − Median) ÷ IQR, threshold ±3

Z-Score — Detection & Removal Python Code
Z-Score se Outliers Detect aur Remove karo
🐍 Python — Z-Score Method
import pandas as pd
import numpy as np

# ─── Inline Dataset: Zomato Delivery Data ───
data = {
    'rider':         ['Raju',  'Suresh', 'Amit',  'Pooja', 'Kiran',
                       'Deepak','Meena',  'Arjun', 'Sunita','Vikram'],
    'delivery_time': [28,     32,      29,     185,    31,
                       27,     30,      26,     220,    33],   # minutes
    'rating':        [4.5,    4.2,     4.6,    4.0,    4.4,
                       4.7,    4.3,     4.8,    3.9,    4.1],
    'orders_today':  [12,     15,      11,     13,     14,
                       10,     16,      9,      12,     15],
}
df = pd.DataFrame(data)

print("Original Data:")
print(df)
print(f"\nTotal rows: {len(df)}")

# ══════════════════════════════════════════
# STEP 1: Z-Score Calculate karo
# ══════════════════════════════════════════
# delivery_time column pe Z-Score lagao
col = 'delivery_time'

mean_val = df[col].mean()
std_val  = df[col].std()

print(f"\nDelivery Time — Mean: {mean_val:.1f} min")
print(f"Delivery Time — Std Dev: {std_val:.1f} min")

# Har row ka Z-Score nikaalo
df['z_score'] = (df[col] - mean_val) / std_val

print("\nZ-Scores for delivery_time:")
print(df[['rider', col, 'z_score']].round(2))

# ══════════════════════════════════════════
# STEP 2: Outliers Identify karo (|Z| > 3)
# ══════════════════════════════════════════
threshold = 3
outliers = df[df['z_score'].abs() > threshold]
print(f"\nOutliers detected (|Z| > {threshold}):")
print(outliers[['rider', col, 'z_score']])

# ══════════════════════════════════════════
# STEP 3: Outliers Remove karo
# ══════════════════════════════════════════
df_clean = df[df['z_score'].abs() <= threshold].copy()
df_clean = df_clean.drop(columns=['z_score'])  # helper column hata do

print(f"\nRows before cleaning: {len(df)}")
print(f"Rows after cleaning:  {len(df_clean)}")
print(f"Outliers removed:     {len(df) - len(df_clean)}")

print("\nMean delivery time BEFORE:", round(df[col].mean(), 1), "min")
print("Mean delivery time AFTER: ", round(df_clean[col].mean(), 1), "min")
# BEFORE: ~62 min (185 aur 220 ki wajah se)
# AFTER:  ~29 min (real average!)
📊 Before cleaning: Mean ≈ 62 min (outliers ne inflate kiya). After cleaning: Mean ≈ 29 min — yeh real delivery time hai! Z-Score ne 185 aur 220 ko successfully detect kiya.

IQR Method — Box Plot ka Jadoo!
+30 XP on scroll
IQR Kya Hai? — Ek Line Mein
IQR (Interquartile Range) = data ka middle 50% ka spread — Q3 − Q1.

Agar koi value Q1 − 1.5×IQR se neeche jaaye ya Q3 + 1.5×IQR se upar jaaye → woh outlier hai!

Ye method Z-Score se zyada robust hai kyunki ye median use karta hai (mean nahi) — outliers ki wajah se affect nahi hota!
IQR — Step-by-Step Samajhte Hain
📋 Data Sort karo
IPL match scores: [48, 155, 158, 162, 165, 168, 170, 172, 175, 310]
Sorted kiya toh easy ho jaata hai quartiles nikalna.
📊 Q1 aur Q3 nikalo (Quartiles)
Q1 (25th percentile) = pehle 25% data ka border = 159
Q3 (75th percentile) = pehle 75% data ka border = 171
Sochte hain: agar 100 log line mein khade hain, Q1 = 25th person, Q3 = 75th person
📐 IQR Calculate karo
IQR = Q3 − Q1 = 171 − 159 = 12
IQR = middle 50% data ka spread. Chhota IQR = tightly packed data.
🚧 Lower aur Upper Fence nikalo
Lower Fence = Q1 − 1.5 × IQR = 159 − 1.5×12 = 159 − 18 = 141
Upper Fence = Q3 + 1.5 × IQR = 171 + 1.5×12 = 171 + 18 = 189
Fence = woh boundary jiske bahar outlier hai. 1.5 = industry standard multiplier.
✅ Fence ke bahar = Outlier!
Lower Fence = 141    Upper Fence = 189

Value 48: 48 < 141 → OUTLIER! (Lower fence ke neeche)
Value 310: 310 > 189 → OUTLIER! (Upper fence se upar)
Values 155–175: 141 ≤ x ≤ 189 → ✅ Normal range
IQR ka Bada Fayda — Robust to Outliers!
IQR Q1 aur Q3 use karta hai — ye dono median-based statistics hain jo outliers se affect nahi hote!

Z-Score mein problem: outlier khud mean aur SD ko badha deta tha, toh Z-Score kuch zyada nahi dikhata tha.
IQR mein: ek outlier fence ko affect nahi karta — boundaries stable rehti hain. Isliye IQR zyada reliable hai!
🤔 Ek dataset mein Q1 = 20, Q3 = 50 hai. IQR method se Upper Fence kya hoga?
AUpper Fence = 95  (Q3 + 1.5 × IQR = 50 + 45)
BUpper Fence = 80  (Q3 + IQR = 50 + 30)
CUpper Fence = −25  (Q1 − 1.5 × IQR)
DUpper Fence = 110  (Q3 + 2 × IQR = 50 + 60)

IQR — Detection & Removal Python Code
IQR se Outliers Detect aur Remove karo
🐍 Python — IQR Method
import pandas as pd
import numpy as np

# ─── Inline Dataset: IPL Match Scores ───
data = {
    'match':  ['M1','M2','M3','M4','M5','M6','M7','M8','M9','M10','M11','M12'],
    'team_A': [165, 172, 158, 48,  170, 162, 168, 175, 310, 160, 163, 169],
    'team_B': [155, 160, 145, 152, 158, 310, 148, 162, 155, 42,  157, 153],
}
df = pd.DataFrame(data)

print("Original Data:")
print(df)

# ══════════════════════════════════════════
# IQR METHOD — team_A column pe apply karo
# ══════════════════════════════════════════
col = 'team_A'

# STEP 1: Q1 aur Q3 nikalo
Q1 = df[col].quantile(0.25)   # 25th percentile
Q3 = df[col].quantile(0.75)   # 75th percentile
IQR = Q3 - Q1

print(f"\n--- team_A Analysis ---")
print(f"Q1 (25th percentile): {Q1}")
print(f"Q3 (75th percentile): {Q3}")
print(f"IQR (Q3 - Q1):        {IQR}")

# STEP 2: Fences calculate karo
lower_fence = Q1 - 1.5 * IQR
upper_fence = Q3 + 1.5 * IQR

print(f"\nLower Fence: {lower_fence}  (is se neeche = outlier)")
print(f"Upper Fence: {upper_fence}  (is se upar  = outlier)")

# STEP 3: Outliers identify karo
outlier_mask = (df[col] < lower_fence) | (df[col] > upper_fence)
print(f"\nOutliers in {col}:")
print(df[outlier_mask][['match', col]])

# STEP 4: Clean data — outliers remove karo
df_clean = df[~outlier_mask].copy()

print(f"\nRows before: {len(df)} | Rows after: {len(df_clean)}")
print(f"Outliers removed: {outlier_mask.sum()}")
print(f"\nMean team_A BEFORE: {df[col].mean():.1f}")
print(f"Mean team_A AFTER:  {df_clean[col].mean():.1f}")
📦 IQR Result: Lower Fence ≈ 141, Upper Fence ≈ 195. Outliers: 48 (collapse) aur 310 (extraordinary score) remove ho gaye. Mean: 192 → 165 — real average score mil gaya!

IQR = Q3 - Q1Middle 50% data ka spread
Q1 - 1.5 * IQRLower Fence — is se neeche outlier

Real India Decision Guide
🏏 IPL Match Scores → IQR (skewed, extreme values possible)
💰 Employee Salaries → IQR (highly skewed distribution)
🏠 Property Prices in Mumbai → IQR (very skewed)
📝 Exam Marks (0–100) → Z-Score (roughly normal)
📊 Manufacturing dimensions → Z-Score (tightly controlled, normal)
🌡️ Temperature readings → Z-Score (seasonal normal)
